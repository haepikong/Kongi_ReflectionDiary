# 배움의 온도

학생과 교사가 수업 성찰 일기와 피드백을 주고받는 브라우저 웹앱입니다.

## 실행 방법

- `index.html`을 브라우저에서 열거나, 정적 웹 서버로 프로젝트 폴더를 실행합니다.
- 마이크 녹음은 HTTPS 또는 localhost 환경과 브라우저 마이크 권한이 필요합니다.
- 자동 받아쓰기는 브라우저의 한국어 음성 인식 지원 여부에 따라 달라집니다. 미지원 브라우저에서는 전사문을 직접 입력할 수 있습니다.

## 체험 계정

- 교사 접속 코드는 처음 실행 시 `2468`입니다. 교사 화면에서 변경할 수 있습니다.
- 체험 학급 코드는 `HAPPY24`와 `HAPPY25`입니다.
- 학생은 첫 로그인 때 8자 이상의 영문자·숫자 비밀번호를 설정합니다. 잊어버린 경우 교사가 학생 비밀번호 관리 탭에서 초기화할 수 있습니다.
- 로그인, 학급, 성찰 기록은 현재 브라우저에 저장됩니다. 다른 기기와 공유하려면 서버와 데이터베이스 연동이 필요합니다.
- 내려받은 ZIP에는 소스 코드와 이미지가 포함됩니다. 브라우저에 저장된 로그인·성찰 데이터는 ZIP에 포함되지 않습니다.

## 파일 구성

- `index.html`: 앱 화면과 동작
- `ai-images/`: 해피콩 캐릭터 이미지
